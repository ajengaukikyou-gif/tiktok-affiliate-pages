Privacy Policy

Effective Date: November 27, 2026

Pabrik Affiliate Bunda respects user privacy and stores zero user data on external servers.

1. Data Collected

During OAuth authorization, TikTok issues an access token and refresh token scoped strictly to video.upload. These tokens are stored solely on the owner's local Windows machine (.env) and are never shared with, sold to, or transmitted to any third party.

2. Data Deletion

The owner may revoke access at any time in TikTok App Settings or delete the local .env credentials file.

3. Kebijakan Privasi (Bahasa Indonesia)

Alat ini tidak mengumpulkan, menyimpan di server pihak ketiga, maupun membagikan data pribadi apa pun. Token OAuth TikTok hanya disimpan secara lokal di komputer pemilik akun.
